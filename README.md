## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_home_overview_core_sector`** serves as the executive overview and core sector showcase for **UNIVERSE HUOKAING THARA Group**. Visitors can explore the organization's primary divisions, filter sectors by focus area, search capabilities in real time, and inspect operational summaries inside an interactive dossier modal.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Search & Core Sector Filtering:** Filter core sectors (*Media & Entertainment, Advertising & Marketing, Cybersecurity & Web Tech*) or search divisions and services in real time.
* **📂 Sector Dossier Modal:** Inspect each division's operational scope, target platforms, and executive oversight inside a modal dialog.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
- **Icons:** FontAwesome v6.4.0
- **UI/UX Design:** Cyberpunk Holographic Dark/Light Theme with Scanline Overlay
